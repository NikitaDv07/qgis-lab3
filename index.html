Карта зданий в зоне затопления, шаг за шагом

Инструкция для тех, кто открывает QGIS впервые. Делайте шаги по порядку и ставьте галочку после каждого. Галочки сохраняются в этом браузере. Ответы на вопросы методички уже посчитаны по вашим данным из архива.

0

Сначала пять слов, без которых непонятно

QGIS — это программа для карт. Она не рисует карту сама, а показывает файлы с данными стопкой, как прозрачные плёнки.

СлойОдна «плёнка» на карте: снимок, здания или зона затопления. Верхний слой закрывает нижние.
Шейп-файл (.shp)Файл с фигурами: точками, линиями или многоугольниками. Состоит из нескольких файлов с одним именем, их нельзя разлучать.
Растр (.tif)Обычная картинка из пикселей, но «приклеенная» к месту на Земле. У нас это спутниковые снимки.
Таблица атрибутовТабличка, где у каждого здания есть строка: этажность, площадь, стоимость, тип.
Система координат (СК)Правило, как перевести «круглую» Землю на плоский экран. Если СК не та, слои разъезжаются.
МакетЛист бумаги А4, на который вы кладёте карту, название, легенду, масштаб и стрелку севера.

  1. Распакуйте архив в простую папку

    Распакуйте Laboratornaya_rabota_3.zip, например, в C:\GIS\Lab3. Короткий путь без пробелов избавит от многих странных ошибок.

    Внутри должны быть файлы:

    • BaseMap.tif (+.tfwx, .aux.xml)
    • FloodZone_Ufa.tif (+.ovr, .aux.xml)
    • Buildings.shp, .dbf, .shx, .prj…
    • FloodZone.shp, .dbf, .shx, .prj…
1.1

Создаём проект и выбираем систему координат

Проект — это файл, который помнит, какие слои вы открыли и как их раскрасили. Систему координат ставим сразу, чтобы все данные легли без искажений.

  1. Откройте QGIS и создайте новый проект

    Пуск → QGIS Desktop (версия 3.x). Затем Проект→Создать или Ctrl+N.

    Слева сверху панель Браузер (как Проводник), под ней панель Слои, в центре белое поле — будущая карта.

  2. Определите зону UTM

    Уфа находится примерно на 56° восточной долготы. Зона 40 покрывает долготы от 54° до 60°, Россия в северном полушарии.

    Ответ

    Зона 40N, система WGS 84 / UTM zone 40N, код EPSG:32640. Ваши шейп-файлы сохранены именно в ней, это проверено по файлам .prj.

  3. Поставьте эту систему проекту

    Щёлкните по надписи EPSG:4326 в правом нижнем углу окна. В поле Поиск введите:

    32640

    В нижнем списке выберите WGS 84 / UTM zone 40N и нажмите OK. Внизу справа теперь написано EPSG:32640.

  4. Сохраните проект

    Проект→Сохранить как, имя Lab1, в ту же папку с данными. Дальше сохраняйте почаще: Ctrl+S.

1.2

Добавляем снимки (растры)

Два снимка: BaseMap — фрагмент города, FloodZone_Ufa — снимок с отмеченной зоной затопления.

  1. Откройте Источник данных → Растр

    Нажмите Ctrl+L (или кнопку с тремя цветными квадратиками и плюсом). Слева выберите вкладку Растр.

  2. Выберите два файла .tif

    В поле «Источник» нажмите …, зайдите в папку с данными, зажмите Ctrl и щёлкните BaseMap.tif и FloodZone_Ufa.tif. Затем Открыть → Добавить → Закрыть.

    Если спросит про преобразованиеЕсли появится окно выбора преобразования координат, просто нажмите OK.

  3. Поставьте FloodZone_Ufa наверх

    В панели Слои перетащите строку FloodZone_Ufa мышью на самый верх списка. Теперь она закрывает BaseMap: что выше в списке, то сверху на карте.

  4. Сделайте верхний снимок полупрозрачным

    Правой кнопкой по FloodZone_Ufa → Свойства… → слева вкладка Прозрачность. Ползунок Общая непрозрачность поставьте на 30 %, нажмите Применить, затем OK.

    Теперь сквозь верхний снимок виден нижний. Посмотрите, совпадают ли реки и дороги на обоих: это и есть «оценить точность привязки».

    BaseMap оказался не на месте?У файла BaseMap.tif координаты записаны в нестандартном файле .tfwx с запятыми вместо точек, и QGIS может их не понять. Тогда снимок окажется далеко или совсем не будет виден. Удалите слой и добавьте вместо него BaseMap_fixed.tif (скачайте по ссылке). Это тот же снимок, но с правильной привязкой.
1.3

Добавляем здания и зону затопления

Это векторные слои: многоугольники с таблицей сведений. Добавим их двумя другими способами, как просит методичка.

  1. Перетащите Buildings.shp в окно QGIS

    Откройте папку с данными в Проводнике Windows и мышью перетащите Buildings.shp прямо на карту. Здания появятся случайным цветом.

  2. Приблизьтесь к зданиям

    Правой кнопкой по слою Buildings → Увеличить до слоя.

  3. Переименуйте слой и исправьте кодировку

    Дважды щёлкните по слою → вкладка Источник:

    • Имя слоя: Здания
    • Кодировка: windows-1251

    Нажмите OK.

    Зачем кодировкаВ архиве файл Buildings.CPG говорит «UTF-8», а текст на самом деле записан в Windows-1251. Без этой настройки вместо «УМПО» и «ПК» будут непонятные символы.

  4. Добавьте FloodZone.shp через панель Браузер

    Если панели «Браузер» не видно: Вид→Панели→Браузер. В её дереве найдите свою папку (например, C:\GIS\Lab3) и дважды щёлкните по FloodZone.shp.

  5. Оформите зону затопления

    Дважды щёлкните по слою FloodZone. Во вкладке Источник задайте имя зона затопления. Затем вкладка Стиль, щёлкните по строке Простая заливка и задайте:

    • Цвет заливки: любой синий;
    • Непрозрачность (ползунок над деревом стиля): 50 %;
    • Цвет обводки: красный;
    • Толщина обводки: 1.

    Нажмите OK и сохраните проект.

    Важно пониматьОформление не меняет сами файлы. QGIS только запоминает в проекте, как их рисовать. Чтобы изменить данные, нужен режим редактирования (карандаш).
1.4

Раскрашиваем здания по стоимости

Вместо одного цвета каждое здание получит оттенок красного по своей стоимости. Тёмные — дорогие. Сразу видно, сколько денег стоит в зоне воды.

  1. Включите «Символизация по диапазонам значений»

    Свойства слоя Здания → Стиль. В самом верхнем выпадающем списке вместо «Простая символика» выберите Символизация по диапазонам значений.

  2. Способ 1: естественные интервалы (Дженкс)

    • Значение: Value
    • Цветовой ряд: Reds
    • Режим (внизу): Естественные интервалы (Дженкс), классов 5

    Нажмите Классифицировать, потом Применить. Отодвиньте окно и посмотрите на карту: мелкие здания должны быть светлыми. Если они тёмные, нажмите стрелку справа от цветового ряда → Инвертировать цвета.

  3. Способ 2: свои границы классов

    Поставьте Классы: 4 и нажмите Классифицировать. Затем дважды щёлкните по числам в колонке Значения каждой строки и введите границы:

    КлассОтДоЗданий всего
    Дешёвые1 700 00050 000 00063
    Средние50 000 0001 000 000 00041
    Дорогие1 000 000 0004 000 000 0008
    Самые дорогие4 000 000 0009 000 000 0007

    Нули вводите полностью, без пробелов: 4000000000. Нажмите OK.

  4. Найдите самое дорогое здание в таблице

    Правой кнопкой по слою → Открыть таблицу атрибутов. Щёлкните по заголовку Value два раза, чтобы самые дорогие оказались сверху. Щёлкните по номеру первой строки слева: здание подсветится синим в таблице и жёлтым на карте.

    Отодвиньте таблицу, но не закрывайте, чтобы видеть карту.

Ответы на вопросы раздела (посчитано по вашим данным)

Самому дорогому зданию соответствует самый большой полигон?
Нет. Самое дорогое — OBJECTID 40, производственный корпус в 7 этажей, ≈ 9,0 млрд руб. Самый большой контур на карте — OBJECTID 39 (≈ 113 900 м²), но он одноэтажный и стоит ≈ 5,2 млрд.
От чего зависит стоимость?
От общей площади (поле Area = площадь контура × этажность) и от типа здания. Стоимость = Area × цена за м²: производственные и хозяйственные корпуса и склад — 46 000 руб./м², административные (АК) — 84 000, коммерческая недвижимость (КН) — 122 000, АЗС — 40 000, КПП и подземные сооружения — 35 000.
Какие здания попали в категорию дорогих?
Дороже 4 млрд — 7 зданий: шесть производственных корпусов (ПК) завода УМПО и один многоэтажный административный корпус (АК, 10 этажей, ул. Ферина 2).
Какие здания попали в зону затопления?
Зону задевают 72 здания из 119, целиком внутри 63. Почти вся южная часть завода. Из 7 самых дорогих в зону попали 6.
1.5

Фильтр: прячем маленькие здания

Фильтр временно скрывает объекты, не удаляя их из файла.

  1. Посчитайте объекты

    В заголовке окна таблицы атрибутов написано «Объектов всего: …».

    Ответ

    В слое Здания 119 объектов. На рисунке 9 методички 57, потому что там уже стоит фильтр из следующего шага.

  2. Поставьте фильтр «площадь больше 1000 м²»

    Правой кнопкой по слою Здания → Фильтр… Дважды щёлкните по полю Area в списке слева, нажмите кнопку > и допишите 1000. Должно получиться:

    "Area" > 1000

    Нажмите Проверить. QGIS ответит, что строк 57. Затем OK. Рядом со слоем появится значок воронки.

    Опечатка в методичкеВ примечании написано «меньше 10000», а правильно «меньше 1000», как в самом задании.

  3. Снимите фильтр и покажите все здания

    Снова Фильтр… → Очистить → OK. Потом правой кнопкой → Увеличить до слоя.

1.6

Подписываем самые дорогие здания

Подпись — тип здания из поля Type (ПК, АК…). Подписываем только выделенные, чтобы карта не превратилась в кашу.

  1. Выделите здания дороже 4 млрд

    Откройте таблицу атрибутов. На её панели нажмите кнопку Выделить объекты, удовлетворяющие условию (значок ε с жёлтым квадратом). Введите:

    "Value" > 4000000000

    Нажмите Выделить объекты. Выделится 7 зданий, на карте они станут жёлтыми. Закройте таблицу.

  2. Включите подписи

    Свойства слоя → Подписи. В верхнем списке выберите Обычные подписи, в поле Значение выберите Type.

  3. Настройте текст и буфер

    • Вкладка Текст: шрифт Times New Roman, размер 12, единицы пиксели, цвет чёрный.
    • Вкладка Буфер: галочка Нарисовать текстовый буфер, размер 0,8, цвет зелёный. Это светлая обводка вокруг букв, чтобы они читались на снимке.
    • Вкладка Размещение: Вокруг центроида, расстояние 0.

  4. Подписывать только выделенные

    Вкладка Отрисовка. Найдите строку Показать подпись, справа от неё кнопка ε → Изменить… Вставьте:

    if(is_selected(), 1, 0)

    OK → Применить. Подписи «ПК» и «АК» появятся только на 7 выделенных зданиях.

    Подпись вылезла за здание?Включите Вид→Панели→Инструменты подписей и подвиньте её мышью.
1.7

Собираем лист карты (макет)

Макет — это лист А4, на который кладутся карта и все обязательные элементы.

  1. Создайте макет

    Проект→Создать макет, введите имя, например «Карта затопления». Откроется отдельное окно с белым листом.

  2. Задайте лист А4

    Правой кнопкой по белому листу → Параметры страницы: размер A4, ориентация Альбомная.

  3. Добавьте карту

    Добавить элемент→Добавить карту, затем нарисуйте мышью рамку почти на весь лист. Карта появится внутри. Двигать содержимое рамки можно кнопкой «Переместить содержимое элемента».

  4. Добавьте остальные элементы

    Всё через меню Добавить элемент, каждый раз рисуя рамку мышью:

    • Подпись — название карты сверху. Текст пишется справа в панели «Свойства элемента».
    • Легенда. Чтобы убрать лишние строки вроде «Канал 1 (Red)», снимите в её свойствах галочку Автообновление и удалите строки кнопкой «минус».
    • Масштабная линейка.
    • Стрелка севера.
    • Ещё одна Подпись с пояснением и вашими ФИО и группой.

  5. Экспортируйте картинку и сохраните

    Макет→Экспорт в изображение, формат PNG. Потом Ctrl+S в окне макета и в главном окне.

Самостоятельное задание: здания под снос

Нужно найти здания, которые стоят в зоне затопления и при этом дешёвые. Их подписать стоимостью, остальные покрасить серым. Ниже самый простой путь. «Дешёвые» берём как первый класс из раздела 1.4: меньше 50 млн руб.

  1. Перекрасьте здания по правилам

    Свойства слоя Здания → Стиль → в верхнем списке Символизация по правилам. Двойным щелчком откройте первое правило и в поле Фильтр вставьте:

    overlay_intersects('зона затопления') AND "Value" < 50000000

    Подпись правила: «Под снос». Цвет яркий, например оранжевый. OK.

    Нажмите зелёный +, чтобы добавить второе правило. Поставьте переключатель Иначе, подпись «Остальные здания», цвет серый. OK → Применить.

    Имя в кавычках важно'зона затопления' — это имя слоя из шага 1.3, буква в букву. Если назвали слой иначе, впишите своё. Функция работает в QGIS 3.16 и новее.

  2. Выделите эти же здания

    Таблица атрибутов → Выделить объекты, удовлетворяющие условию → вставьте то же выражение, что выше → Выделить объекты.

    Проверка

    Должно выделиться 37 зданий: мелкие производственные и хозяйственные корпуса, две АЗС, подземные сооружения.

    Старый QGIS и функция не работает?

    Вектор→Выборка→Выбрать по расположению: из слоя «Здания», где объекты пересекаются со слоем «зона затопления» → Выполнить. Затем в таблице «Выделить по условию» с "Value" < 50000000, и в кнопке Выделить объекты выберите Отфильтровать текущее выделение. Для раскраски тогда используйте правило is_selected().

  3. Подпишите их стоимостью

    Подписи → Обычные подписи. В поле Значение нажмите ε и вставьте:

    format_number("Value" / 1000000, 1) || ' млн'

    В Отрисовка → Показать подпись оставьте if(is_selected(), 1, 0) из раздела 1.6. Размер шрифта лучше уменьшить до 8–9: зданий много, и они мелкие.

  4. Сделайте макет и выгрузите PNG

    Как в разделе 1.7: карта, название (например, «Здания под снос в зоне затопления»), легенда, масштабная линейка, стрелка севера. Экспорт в PNG.

Ответы на контрольные вопросы

1. Для чего используется Конструктор запросов?

Чтобы составлять условия по атрибутам, например "Area" > 1000, и по ним фильтровать или выделять объекты. Поля и операторы добавляются щелчками, поэтому синтаксис получается правильным.

2. Какие функции выполняют слои карты?

Слой связывает файл с данными и карту и задаёт, как его рисовать: цвет, символы, прозрачность, подписи, порядок наложения. Один набор данных можно добавить несколькими слоями с разным оформлением, сам файл при этом не меняется.

3. Как изменить имя слоя?

Правой кнопкой по слою → «Переименовать слой». Или «Свойства» → «Источник» → «Имя слоя».

4. Как задать ширину и цвет контура?

Свойства слоя → «Стиль» → строка «Простая заливка» → «Цвет обводки» и «Толщина обводки».

5. Что такое фильтрация и как её настроить?

Фильтрация показывает и использует в анализе только объекты, подходящие под условие, но не удаляет остальные из файла. Правой кнопкой по слою → «Фильтр…» → условие в конструкторе → «Проверить» → OK.

6. Перечислите элементы карты.

Сама карта, название, легенда, масштабная линейка, стрелка «север–юг», текстовое пояснение. Иногда также координатная сетка и врезка-обзорная карта.

Если что-то не работает

Вместо русских букв в таблице «кракозябры»

Свойства слоя → «Источник» → «Кодировка» → windows-1251.

Снимок BaseMap не совпадает со зданиями или не виден

Удалите слой BaseMap и добавьте BaseMap_fixed.tif. Положите его в папку с остальными данными.

Ничего не видно на карте после добавления слоя

Правой кнопкой по слою → «Увеличить до слоя». И проверьте, стоит ли галочка рядом с именем слоя.

Выражение подчёркнуто красным или «Ошибка выражения»

Имена полей пишутся в двойных кавычках ("Value"), текст и имена слоёв в одинарных ('зона затопления'). Числа без пробелов. Скопируйте выражение кнопкой «Копировать» на этой странице.

Подписи не появились

Проверьте, что нужные здания выделены (жёлтые). Если выделение снялось, подписи с условием is_selected() пропадут. Выделите их заново.

Не видно панели «Браузер» или «Слои»

Вид→Панели → поставьте галочки у нужных.
